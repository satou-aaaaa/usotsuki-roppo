# うそつき六法

夜の村をまわり、村人が話す法律が「正しい」か「間違い」かを見分ける学習ゲームです。ブラウザだけで遊べます。

- 村人は一人ずつ訪ねます。答えるとすぐに条文と解説が出ます。
- 一晩に5つの村。村の4人を全部見分けると次の村は難しく、半分以下なら易しくなります（正解率8〜9割がちょうどよい難しさ）。
- 見誤った話は、翌日以降の村にまた出てきます。記録はあなたのブラウザにだけ残ります。
- 話は「天秤の書」で一次資料と照らし合わせた問題・解説をもとにしています。法律相談ではありません。

## 開発

```bash
bash scripts/setup.sh
node qa/run.mjs
```
