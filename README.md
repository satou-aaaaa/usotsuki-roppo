# うそつき六法

夜のうちに「ねじれ文字」が六法の言葉をうそに書き換えました。本を1ページずつ開き、うその言葉を見つけて、正しい札で封じる学習ゲームです。ブラウザだけで遊べます。

- 本棚に憲法・民法・刑法・商法・民事訴訟法・刑事訴訟法の6冊（各10ページ・全60ページ）。どの巻からでも開け、1回に6ページずつ読みます。
- うその言葉をタップ → 3枚の札から正しい言葉を選ぶと、ねじれ文字を札に封じます。うその無いページもあります。
- 各巻の最後には大きなねじれ文字。逃がした魔は、巻の終わりにすぐ追い直せます。封じた魔は「封じ帳」に並びます。
- 6冊を取り戻すと夜明け。記録はあなたのブラウザにだけ残ります。
- 条文は「天秤の書」の照合済みの問題と e-Gov 法令検索で確かめています。法律相談ではありません。
- 前の版（夜の村で見分ける）は classic.html で遊べます。

## 開発

```bash
bash scripts/setup.sh
node qa/run.mjs
```
